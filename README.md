# Распределение по ГИБ

Программа находит в назначениях платежей все `ГИБ XXXX-сумма` и раскладывает суммы по столбцам ГИБ.
Нет столбца — создаёт (по возрастанию кода; итоги «Ҷамъ» и «Ҳамагӣ» растягиваются сами).

## Как пользоваться
1. Откройте программу и перетащите в неё файл выписки (или нажмите и выберите).
2. Программа покажет, сколько назначений с ГИБ нашла и какие столбцы ГИБ создаст.
3. Нажмите **«Заполнить ГИБ»** — суммы встанут в столбцы ГИБ той же строки, файл сохранится на месте.

Программа сама находит лист, столбец с назначениями и строку заголовков. Пустые столбцы ГИБ, которые
уже есть в файле, используются; недостающие создаются по порядку кодов. Всё вписанное подсвечивается
зелёным. Строки, где суммы уже стоят, пропускаются — запускать повторно безопасно.
Перед изменением делается копия в папку `_резервные копии` рядом с файлом.

## Сверка с выпиской: «Расходы» и «Разница»
При заполнении и при встраивании автоматики добавляются столбцы (порядок: `Расходы | Разница | Ҳамагӣ | ГИБ…`):
- **Расходы** — сумма платежа из выписки (в выписке этот столбец уже есть, в Бучет его вставляют вручную);
- **Разница** = «Ҳамагӣ» − «Расходы», формула в каждой строке. Ненулевая разница подсвечивается красным,
  в строке итогов — общая разница (0 — всё сошлось). После проверки «Расходы» можно скрыть.

## Сравнить по ИНН
Если в файле есть лист, в названии которого есть слово сравнения, а на листе два списка организаций
с ИНН / РМА, появляется кнопка **«Сравнить по ИНН»**. Ключевые слова (по корню, регистр и таджикские
буквы не важны): муқоиса, фарқ / фарқият, тафовут, қиёс, мутобиқат, тағйирот, санҷиш…; сравнение,
различие, разница, сверка, сопоставление, расхождение…; compare, diff, delta, reconcile, vs…

Создаётся новый файл `имя — различия.xlsx` (исходный не меняется) с листами: **Итог**, **Новые**,
**Пропавшие**, **Изменения** (было → стало → разница по каждому показателю), **Дубликаты**.
Сопоставление идёт по ИНН, поэтому разное написание названий не мешает.

## Встроить автоматику в Excel
Кнопка **«Встроить автоматику в Excel»** создаёт рядом копию файла `имя (автоматика).xlsm` с макросом
(исходный файл не меняется). Дальше программа не нужна: в Excel нажмите «Включить содержимое» и
вставляйте назначения — ГИБ проставляются сами. Вверху листа есть кнопка «Пересчитать ГИБ»;
если макросы выключены, видна красная надпись.

Макрос работает только на листе, который выбрала программа (скрытые имена листа `GIB_ON`,
`GIB_HDR`, `GIB_COL`). Код макроса — `assets/modGIB.bas.txt`, шаблон — `assets/gib_template.xlsm`.
Пересобрать шаблон после правки макроса: `python assets/build_template.py <Макрос.xlsm>`
(только для разработчика: нужен Excel с включённым «Доверять доступ к объектной модели проектов VBA»).

## Требования
- Windows и установленный Microsoft Excel (режим 1 пишет через Excel — сохраняются картинки и формулы).

## Запуск из исходников
```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python gib_app\main.py
```

## Сборка
`build.bat` → `dist\GIB.exe` (один файл, Python у пользователя не нужен).
Если установлен Inno Setup 6, там же собирается установщик `dist\GIB-Setup.exe`. Иконка: `assets/make_icon.py`.
