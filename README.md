# Распределение по ГИБ

Программа находит в назначениях платежей все `ГИБ XXXX-сумма` и раскладывает суммы по столбцам ГИБ.
Нет столбца — создаёт (по возрастанию кода; итоги «Ҷамъ» и «Ҳамагӣ» растягиваются сами).

## Как пользоваться
При запуске выберите, что делаем: **ГИБ** или **Глубокий анализ** (Excel по организациям: что случилось и ошибки).

**ГИБ → «Заполнить ГИБ»** (два файла):
1. Выберите выписку (столбцы «Основание», «Расходы», «№ док-та», «Дата Док-а»).
2. Выберите файл, куда заполнить (например, Бучет; лист с «Номгӯи корхонаҳо» находится сам,
   если подходящих листов несколько — можно выбрать).
3. Нажмите **«Заполнить ГИБ»**: платежи допишутся после последней заполненной строки
   (назначение, «№ ҳуҷҷат», «Сана», «Расходы», номер р/т); не хватит места до «Чамъ» — строки
   добавятся, итоги растянутся. Платежи, которые уже были перенесены раньше, пропускаются.
   Затем суммы сразу раскладываются по ГИБ (как ниже).

**ГИБ → «Встроить автоматику в Excel»** (один файл) — см. раздел ниже.

**Глубокий анализ** (любые файлы, можно несколько) — см. раздел ниже.

Программа сама находит лист, столбец с назначениями и строку заголовков. Пустые столбцы ГИБ, которые
уже есть в файле, используются; недостающие создаются по порядку кодов. Всё вписанное подсвечивается
зелёным. Строки, где суммы уже стоят, пропускаются — запускать повторно безопасно.
Перед изменением делается копия в папку `_резервные копии` в корне проекта (рядом с программой).

## Сверка с выпиской: столбец «Расходы»
Как в «Банк+муҳосибӣ (Бучет) -ислох шуда.xlsm»: проверочный столбец **«Расходы»** стоит сразу за **«Ҳамагӣ»**
и в суммы ГИБ не входит; столбцы ГИБ — правее. Сумма из выписки в «Расходы» заменяется формулой баланса
`=ROUND(Ҳамагӣ − сумма; 2)`: 0 — сумма совпала, иначе ячейка красная (сама сумма видна в строке формул).
Итог баланса — в строке «Чамъ». У ячейки с балансом не 0 — примечание (видно при наведении):
«По назначению: 3 250,00 · По выписке: 3 350,00 · Разница: −100,00 — в назначении на 100,00 меньше». В выписке «Ҳамагӣ» создаётся перед её столбцом «Расходы».

Правила ГИБ — как в образце: код 3–8 цифр; если цифр больше 4, это смета с подпунктом — берутся первые 4
(«ГИБ 22111-600» и «ГИБ 22112-550» → 1150 в столбце 2211), такая строка подсвечивается жёлтым для проверки.
При повторном заполнении строка заполняется заново по тексту: суммы ГИБ, которых в назначении больше нет, стираются.

## Глубокий анализ
Выберите файлы — любые, можно сразу несколько: реестры платежей (выгрузки казначейства, например M1-4, M5-8,
M9-12) и обычные таблицы с ИНН (например «30 фоиза»). Схема Excel не важна: программа сама находит все
таблицы с ИНН на всех листах, реестры узнаёт по столбцам «Плательщик / ИНН / Получатель / Сумма» (русский,
таджикский, английский; если не узнала — предложит указать столбцы или читать файл как список организаций).

Нажмите **«Анализировать»** — получится Excel (папка `Свод по глубокому анализу` в корне проекта; исходные
файлы не меняются):
- лист **«Анализ»**: каждая организация (ИНН) — одна строка, суммы по каждой найденной **части** (файл
  реестра / период, таблица на листе; если в таблице нет сумм — «есть»), всего, «Названий» (сколько написаний);
- **цвет строки** — что случилось между первой и последней частью: Новый · Пропал · Вырос · Уменьшился ·
  Без изменений · Появился и пропал;
- столбец **«Ошибки»** (оранжевая ячейка): двойной платёж, неправильный ИНН, странная дата, повтор ИНН;
- сверху легенда; при наведении на заголовок или цвет — подсказка, что это значит; отбирать — фильтром Excel;
- лист **«Ошибки подробно»**: каждая ошибка строкой — файл, строка, документ, что не так, как должно быть.

**Сводная таблица** (кнопка «Сводная таблица», отдельный файл «Сводная …»): лист «Данные» (одна строка —
организация в одной части) и настоящая сводная таблица Excel на листе «Сводная»: что случилось → организации
(«+» раскрывает), части по столбцам, итоги; сверху срезы — кнопки-фильтры «Кто», «Что случилось», «Ошибки»,
«Часть». В срезе «Кто» по умолчанию выбраны плательщики (иначе каждый платёж посчитается дважды). Поля можно
перетаскивать как в любой сводной. Строит её сам Excel (нужен установленный Excel).

**Платежи одной организации**: на том же экране введите ИНН и нажмите «Платежи этого ИНН — в Excel» (анализ
запускать не нужно). Получится файл «Платежи ИНН …» с листами «Платил» и «Получал» (по датам, с суммой
в заголовке). ИНН можно вводить с пробелами или без нуля в начале. Ищется только в реестрах платежей;
если ИНН не найден — программа скажет об этом и пустой файл не создаст.

## Встроить автоматику в Excel
Кнопка **«Встроить автоматику в Excel»** (макрос из «…-ислох шуда.xlsm»: «Пересчитать ГИБ», «Добавить строки»,
«Зафиксировать распределение», «Снять фиксацию») создаёт рядом копию файла `имя (автоматика).xlsm` с макросом
(исходный файл не меняется). Дальше программа не нужна: в Excel нажмите «Включить содержимое» и
вставляйте назначения — ГИБ проставляются сами. Вверху листа есть кнопка «Пересчитать ГИБ»;
если макросы выключены, видна красная надпись.

«Зафиксировать распределение» (как в новой версии Бучета): пометка ставится на сами суммы по статьям
(формат `0.00;-0.00;0.00;@`, выглядит как `0.00`), поэтому назначения потом можно менять как угодно —
вручную, вставкой сразу многих строк — суммы не пересчитаются. Строки, которые дописывает программа
(«Заполнить ГИБ»), пометку от соседней строки не наследуют.

Макрос работает только на листе, который выбрала программа (скрытые имена листа `GIB_ON`,
`GIB_HDR`, `GIB_COL`). Код макроса — `assets/modGIB.bas.txt`, шаблон — `assets/gib_template.xlsm`.
Пересобрать шаблон после правки макроса: `python assets/build_template.py <Макрос.xlsm>`
(только для разработчика: нужен Excel с включённым «Доверять доступ к объектной модели проектов VBA»).

## Требования
- Windows и установленный Microsoft Excel (режим 1 пишет через Excel — сохраняются картинки и формулы).

## Запуск из исходников
```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python gib_app\main.py
```

## Сборка
`build.bat` → `dist\GIB.exe` (один файл, Python у пользователя не нужен).
Если установлен Inno Setup 6, там же собирается установщик `dist\GIB-Setup.exe`. Иконка: `assets/make_icon.py`.
