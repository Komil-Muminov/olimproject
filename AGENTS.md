# Olim GIB Project - Инструкции для разработчиков и агентов

## Главное правило размера файлов (200 строк)
* **Размер любого компонента/файла кода не может превышать 200 строк.**
* Любые крупные модули обязаны быть разделены на специализированные подмодули.
* Стили интерфейса, константы, генераторы отчетов и низкоуровневые операции выносятся в отдельные файлы.

Подробности см. в [.agents/rules/code_style.md](file:///.agents/rules/code_style.md).
